# Tetris

Proyecto desarrollado en TypeScript como parte de la materia Paradigmas.

## Descripción

Este proyecto implementa el juego Tetris utilizando programación
orientada a objetos.

## Tecnologías utilizadas

- TypeScript
- Node.js
- Vitest
- Git
- GitHub

## Instalación

Clonar el repositorio:

git clone https://github.com/macho9991/tetrominos-ucp

Instalar las dependencias:

npm install

## Ejecución

npm run dev

## Tests

Para ejecutar las pruebas:

npx vitest run

## Cobertura

Para ejecutar las pruebas con cobertura:

npx vitest run --coverage
